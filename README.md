## Featured Projects

### BusNow: Real-Time College Bus Tracker
[View Repository](YOUR_BUSNOW_GITHUB_URL) · [Live Demo](YOUR_BUSNOW_VERCEL_URL)

A full-stack application that lets students track their college bus live on a map.

- Driver app streams GPS location every 5 seconds through Socket.io WebSocket rooms.
- Students see the bus on a live Leaflet.js map with a dynamic ETA calculated from live coordinates and stop distances.
- Push notifications are triggered when the bus is within 10 minutes of a student's stop.
- Role-based admin panel with JWT authentication to manage routes, stops, and driver assignments.
- Deployed on Vercel with environment-based configuration; map rendering optimized for low-latency updates across 50+ concurrent student sessions.

**Tech stack:** `Node.js` `Socket.io` `Leaflet.js` `JWT` `Vercel`

### CampusCart: Hyperlocal Student Marketplace
[View Repository](YOUR_CAMPUSCART_GITHUB_URL)

A marketplace for buying and selling within a campus community, with separate buyer and seller roles.

- RESTful Spring Boot backend secured with Spring Security and JWT for buyer/seller role management.
- Redis powers real-time "X people viewing this" counters and TTL-based auto-expiring listings.
- Relational MySQL schema covering users, listings, categories, and transaction history, with pagination.
- React frontend with category filtering, image upload, and search.
- Seller dashboard with listing analytics and buyer inquiry management; Nodemailer sends transaction status email notifications.
- APIs secured with CORS policies and input validation; Cloudinary used for scalable image storage with CDN delivery.

**Tech stack:** `Java` `Spring Boot` `Spring Security` `JWT` `MySQL` `Redis` `React.js` `Nodemailer` `Cloudinary`
