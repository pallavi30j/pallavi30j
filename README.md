## 🚀 Featured Projects

### 🚌 [BusNow](https://github.com/pallavi30j/BusNow): Real-time College Bus Tracker
Live GPS tracking so students always know when their bus is arriving. Drivers stream location over WebSockets (Socket.io), students watch it on a Leaflet.js map with live ETAs and get notified when the bus is close. Includes a JWT-secured admin panel.
`Node.js` `Socket.io` `Leaflet.js` `JWT`

### 🛒 [CampusCart](https://github.com/pallavi30j/CampusCart): Hyperlocal Student Marketplace
A campus marketplace where students buy and sell with role-based access. Spring Boot + Spring Security backend, React frontend, MySQL for data, and Redis for live viewer counts and auto-expiring listings.
`Spring Boot` `React` `MySQL` `Redis`
