## 🚀 Featured Projects

### 🚌 [BusNow](https://github.com/pallavi30j/BusNow): Real-time College Bus Tracker

Never miss your college bus again. BusNow gives students live visibility into where their bus is and when it will reach their stop.

- 📡 Driver app streams GPS location every **5 seconds** using **Socket.io WebSocket rooms**
- 🗺️ Students see the bus moving live on a **Leaflet.js** map with a **dynamic ETA** calculated from live coordinates and stop distances
- 🔔 Push notifications fire when the bus is within **10 minutes** of a student's stop
- 🔐 Role-based **admin panel with JWT authentication** to manage routes, stops, and driver assignments
- ⚡ Map rendering optimized for low-latency updates across **50+ concurrent student sessions**
- ☁️ Deployed on **Vercel** with environment-based configuration

**Tech:** `Node.js` `Socket.io` `Leaflet.js` `JWT` `Vercel`

### 🛒 [CampusCart](https://github.com/pallavi30j/CampusCart): Hyperlocal Student Marketplace

A marketplace built for campus life, where students can buy and sell items safely within their own community.

- 🔐 **Spring Boot** REST backend with **Spring Security & JWT** for buyer and seller role management
- 👀 **Redis** powers real-time "X people viewing this" counters and TTL-based auto-expiring listings
- 🗄️ Relational **MySQL** schema covering users, listings, categories, and transaction history, with pagination
- 🎨 **React** frontend with category filtering, image upload, and search
- 📊 Seller dashboard with listing analytics and buyer inquiry management
- 📧 **Nodemailer** email notifications for transaction status updates
- 🛡️ Secured APIs with CORS policies and input validation; **Cloudinary** for scalable image storage with CDN delivery

**Tech:** `Spring Boot` `Spring Security` `React` `MySQL` `Redis` `Cloudinary` `Nodemailer`
